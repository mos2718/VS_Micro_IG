# The purpose of the repository
- 訂立 vital signs 中體溫、心率、血氧、呼吸  Micro-IG
-- 包含 FHIR observation JSON 欄位定義檔，以及體溫、心率、血氧、呼吸內容差異 CSV diff.csv
- Establish a Micro-IG for vital signs, including body temperature, heart rate, blood oxygen, and respiratory rate.
-- This should include the FHIR Observation JSON field definition files, as well as a CSV file (diff.csv) detailing the content differences among temperature, heart rate, blood oxygen, and respiration.
